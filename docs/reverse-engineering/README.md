# 逆向研究目录

本目录保存对仓库外部注入脚本、游戏 H5 运行时和混淆代码的专题研究。研究记录区分三种证据：

- **直接确认**：静态源码、AST 结构或隔离运行时实验可以重复得到的事实。
- **高置信推断**：由多个直接事实拼出的控制流，但尚未在真实 H5 战斗中闭环。
- **待验证**：需要新的被动抓包、官方 TGA 日志或明确授权的单场测试才能确认的行为。
