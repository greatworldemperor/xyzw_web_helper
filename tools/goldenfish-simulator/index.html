🔴 master 2026-09-28 四条澄清 + 「有保底」二次修正（已全部落进代码）：
1. 「开箱」= 开普通道具，不是开宝箱。 宝箱只产宝箱积分，对「拿金鱼」没有直接产出（它只是积分/兑换的中间物）。 开普通道具产出特殊道具按 「期望值 + 有界线性 bias」建模（master 原话： 「有保底，特殊道具数 = 普通道具数 × 0.25 + bias，bias ∈ [-5,5]，取整数， bias 概率给个线性的就行了，不需要真的用正态分布」）： base = n×0.25，结果 = clamp(round(base + bias), 0, n)， bias 是 [-5,5] 的整数、概率线性（峰在 0，权重 1-2-3-4-5-6-5-4-3-2-1）。 ⇒ 模拟器已删掉「保底次数」参数，也彻底删掉正态分布（normalRandom 已移除）。
  为什么这等价于「有保底」：|bias| ≤ 5 ⇒ 偏差绝对有界， 开 1030 个道具时相对偏差 ≤ 1.94%；且权重对称 ⇒ E[bias] = 0（期望不漂）。 对比之下正态模型的 σ ≈ 13.9 远大于 5，会明显低估成功率。
2. 「达成一轮就能领一轮」 ⇒ 已完成但未领的档位可以逐轮补领 （missionId = (slot-1)×20 + round，见下方「已领奖记录」）。
3. 买鱼竿的金砖计入活动进度，这正是完成金砖消耗任务的主要手段。
4. 周四先补满钓鱼 1300 次（下限），再「看情况决定是否继续做下去」 ⇒ 1300 是下限，不是上限；钓鱼硬上限是 1750（20 轮全满）。
5. 鱼竿有 10% 返还率（master 2026-09-28 补充）： 每次钓鱼期望净消耗 0.9 根 ⇒ x 根鱼竿可钓 x/0.9 次。 钓鱼补满要买的根数按 次数 × 0.9 折算（金砖维度不变——金砖任务看的是花出去的金砖， 返还的是鱼竿不是金砖）；库存鱼竿也按 ÷0.9 折算成可钓次数。
6. 2 轮金砖换 1 轮钓鱼（master 2026-09-28 拍板，默认策略）： 观察点 = 宝箱招募做满 + 金砖 38 万（轮 17）/ 钓鱼 1300（轮 17） → 开道具看实际特殊数 → 按 25% 找任意可行解 → 金砖可做轮数 ≥2 且钓鱼有档，就把 2 轮金砖（8 万）的份额 改买 1 轮钓鱼的杆（135 根 = 8.1 万） —— 杆钱计入金砖任务 ⇒ 金砖进度不减、 钓鱼白捡一档（24 道具）。收敛参考线 = 46 万（轮 19），第 20 轮金砖（4 万 → 12 道具） 是全链唯一低效支出，靠杆钱顺带跨过、不专门做。 蒙特卡洛：观察点 + 2换1 成功率 100%（600 种子，终态均值 252.7、区间 [250, 260]）。
最后兜底（master 2026-09-28 拍板）：如果运气不好还差几个特殊道具， 就补一轮金砖（≈4 万金砖 → 12 个道具 → 期望 +3 特殊）—— 游戏对特殊道具有强控制（实际出率紧贴 25%，偏差极小）， 按 25% 找到的可行解落地后缺口只剩几个 ⇒ 补一轮金砖一定会够，不存在补不够的情况。 这是 46 万收敛线的合法例外（第 20 轮平时不做，保命时随叫随到）。
⇒ 由此修正的一个大结论（被修正了三次）： ① 把 1300 当硬上限 ⇒ 钓鱼只到 17/20 轮 ⇒ 道具上限被算成 978、成功率 ~20%； ② 改回 1750 上限 ⇒ 本期道具上限 = 1050； ③ 把正态换成有界 bias ⇒ 成功率 99.5%（600 种子蒙特卡洛，区间 [249, 268]）。 钓鱼这一步几乎白送：金砖做满要买 ~800 根鱼竿，这些鱼竿本来就得消耗掉， 顺手就把钓鱼从 1300 推到 1750（1300 + 800 = 2100，早超了）。
周四执行顺序：补满宝箱 100000 + 招募 4000 → 钓鱼先补到 1300 → 「看情况」由买鱼竿继续往 1750 推 → 领奖 → 开道具 → 补档循环。

✅ 开道具返还 —— 原文第 118-120 行（期望值）：每个道具 ≈ 0.5 招募令 / 0.205 铂金箱 / 107.304 金砖 / 0.25 特殊道具。
  🔴 四项是「同时获取」，不是多选一（master 澄清）—— 各自独立结算， 一个道具可以同时贡献四项，也可以四项都空。「以 0.205 为准」也已确认（第 80 行的「0.2」是简化写法）。
  为什么叫「期望值」：以铂金箱为例，真实分布是 4.5%→2 个 / 1.1%→5 个 / 0.6%→10 个， 加权和 = 0.205（精确吻合）；而三者相加只有 6.2%，其余 93.8% 一个都不掉。 ⇒ 单次方差极大，只有开成百上千个才收敛。 （master 口述的 6.1% 是心算滑了一下：4.5+1.1+0.6 = 6.2%。）
